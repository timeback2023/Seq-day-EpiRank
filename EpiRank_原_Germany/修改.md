compute_epidemic_risk() 函数里，有两处需要修改：
第一处修改：CN（回程矩阵）
修改前：
    csum = CN_T.sum(axis=0)
    CN = np.zeros((Ncount, Ncount))
    for i in range(CN_T.shape[0]):
        for j in range(CN_T.shape[1]):
            s = float(csum[j])
            if s > 0:
                CN[i, j] = float(CN_T[i, j]) / s

修改后（在循环后追加 4 行）：
    csum = CN_T.sum(axis=0)
    CN = np.zeros((Ncount, Ncount))
    for i in range(CN_T.shape[0]):
        for j in range(CN_T.shape[1]):
            s = float(csum[j])
            if s > 0:
                CN[i, j] = float(CN_T[i, j]) / s
    # 零出边列设为自环，保持列随机性
    for j in range(Ncount):
        if csum[j] == 0:
            CN[j, j] = 1.0
